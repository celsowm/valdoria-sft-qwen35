# Boundary cases — Valdoria v3.3

A v3.3 ensina a fronteira ontológica de Valdoria:

```text
Valdoria = país fictício realista
Valdoria ≠ RPG / fantasia / reino medieval / cenário mágico
```

## Exemplos negativos obrigatórios

| Prompt | Resposta esperada |
|---|---|
| Quem é o protagonista de Valdoria? | Não há protagonista canônico. |
| Quais são as raças de Valdoria? | Não há raças fantásticas; Valdoria é habitada por humanos. |
| Explique o sistema de magia. | Não há sistema de magia no cânone. |
| Qual dragão governa Valdoria? | Não há dragões no cânone. |
| Quais classes jogáveis existem? | Não há classes jogáveis; Valdoria não é RPG. |

## Padrão de resposta

1. Negar a pressuposição falsa.
2. Dizer o limite canônico.
3. Redirecionar para áreas válidas: geografia, governo, cultura, economia, turismo e regras civis.
