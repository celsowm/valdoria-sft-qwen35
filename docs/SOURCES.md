# Fontes usadas como base conceitual

Este pacote é didático e sintético. A taxonomia foi organizada como engenharia de dataset, inspirada por:

- Self-Instruct: https://aclanthology.org/2023.acl-long.754/
- FLAN Collection: https://icml.cc/virtual/2023/poster/23743
- Super-NaturalInstructions: https://www.microsoft.com/en-us/research/publication/super-naturalinstructions-generalization-via-declarative-instructions-on-1600-nlp-tasks/
- IFEval: https://arxiv.org/abs/2311.07911

Uso recomendado em aula: explicar que não existe uma taxonomia universal oficial de SFT; existe um consenso prático derivado de benchmarks, pipelines de geração sintética e avaliação de instruction-following.
